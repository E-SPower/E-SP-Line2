# E-SP-Line2

平台化接入器管理系统 - Platform Adapter Management System

## 快速开始

### 环境要求

- Go 1.22+
- Node.js 18+
- pnpm 或 npm
- Redis (可选)
- PostgreSQL (可选，默认使用 SQLite)

### 后端启动

```bash
# 安装依赖
make deps

# 运行服务
make run
```

后端服务将在 `http://localhost:8080` 启动。

### 前端启动

```bash
cd web

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

前端开发服务器将在 `http://localhost:3000` 启动。
