# 适配器配置

## 概述

适配器是连接电商平台的核心组件，负责消息的接收和发送。每个适配器实例对应一个具体的账号或店铺。

## 支持的适配器

### 淘宝适配器（Taobao Adapter）

**能力**：
- 接收文本消息
- 接收图片消息
- 发送文本消息
- 发送图片消息
- 上传媒体文件
- 获取历史消息
- 创建会话

**配置要求**：
- Cookie：淘宝登录 Cookie
- Device ID：设备标识（可选）

### 闲鱼适配器（Xianyu Adapter）

**能力**：
- 接收文本消息
- 接收图片消息
- 发送文本消息
- 发送图片消息
- 上传媒体文件
- 获取历史消息
- 创建会话
- 获取商品信息

**配置要求**：
- Cookie：闲鱼登录 Cookie
- Device ID：设备标识（可选）

## 创建适配器实例

### 步骤 1：选择适配器包

在"适配器管理"页面，点击"创建实例"，选择需要的适配器包。

### 步骤 2：填写配置

#### 淘宝适配器配置

```json
{
  "cookie": "your_taobao_cookie_here",
  "device_id": "optional_device_id",
  "heartbeat_interval": 15,
  "reconnect_delay": 5
}
```

#### 闲鱼适配器配置

```json
{
  "cookie": "your_xianyu_cookie_here",
  "device_id": "optional_device_id",
  "heartbeat_interval": 15,
  "reconnect_delay": 5
}
```

### 步骤 3：配置路由规则

为适配器实例配置路由规则，决定消息如何分发。

### 步骤 4：启动实例

点击"启动"按钮，系统会：
1. 验证配置
2. 连接到平台
3. 开始接收消息

## 获取 Cookie

### 淘宝 Cookie

1. 打开浏览器，访问 https://www.taobao.com
2. 登录你的淘宝账号
3. 按 F12 打开开发者工具
4. 切换到"Network"标签
5. 刷新页面
6. 找到任意请求，查看 Request Headers
7. 复制 `Cookie` 字段的全部内容

### 闲鱼 Cookie

1. 打开浏览器，访问 https://www.goofish.com
2. 登录你的闲鱼账号
3. 按 F12 打开开发者工具
4. 切换到"Network"标签
5. 刷新页面
6. 找到任意请求，查看 Request Headers
7. 复制 `Cookie` 字段的全部内容

## 适配器状态

适配器实例有以下状态：

- **Stopped**：已停止
- **Starting**：启动中
- **Running**：运行中
- **Stopping**：停止中
- **Error**：错误状态
- **Disconnected**：已断开连接

## 监控适配器

### 连接状态

在"适配器管理"页面可以查看：
- 当前状态
- 连接时间
- 最后心跳时间
- 消息计数
- 错误计数

### 日志查看

点击适配器实例的"日志"按钮，可以查看：
- 连接日志
- 消息收发日志
- 错误日志

## 适配器管理

### 启动/停止

- **启动**：建立与平台的连接，开始接收消息
- **停止**：断开连接，停止接收消息

### 重启

重启适配器会：
1. 停止当前连接
2. 重新验证配置
3. 建立新连接

### 删除

删除适配器实例会：
1. 停止实例（如果正在运行）
2. 删除配置数据
3. 删除相关路由规则

## 最佳实践

### Cookie 管理

1. **定期更新**：Cookie 会过期，建议定期更新
2. **安全存储**：Cookie 包含敏感信息，确保存储安全
3. **监控状态**：关注适配器状态，及时发现 Cookie 失效

### 性能优化

1. **心跳间隔**：根据平台要求设置合适的心跳间隔
2. **重连策略**：配置合理的重连延迟和最大重试次数
3. **队列大小**：根据消息量调整队列大小

### 故障处理

1. **自动重连**：系统会自动尝试重连
2. **错误告警**：配置错误告警，及时发现问题
3. **日志分析**：定期分析日志，优化配置

## 故障排除

### Cookie 失效

**症状**：适配器状态变为 Error，日志显示认证失败

**解决**：
1. 重新获取 Cookie
2. 更新适配器配置
3. 重启适配器

### 连接超时

**症状**：适配器状态为 Starting，长时间无法变为 Running

**解决**：
1. 检查网络连接
2. 检查平台服务状态
3. 增加超时时间配置

### 消息丢失

**症状**：部分消息没有收到

**解决**：
1. 检查路由规则配置
2. 查看消息追踪日志
3. 确认下游应用在线

## 高级配置

### 自定义心跳间隔

```json
{
  "heartbeat_interval": 30
}
```

### 自定义重连策略

```json
{
  "reconnect_delay": 10,
  "max_retries": 5
}
```

### 代理配置

```json
{
  "proxy": {
    "host": "proxy.example.com",
    "port": 8080,
    "username": "user",
    "password": "pass"
  }
}
```
