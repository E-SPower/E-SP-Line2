# 快速开始

## 简介

E-SP-Line2 是一个平台化接入器管理系统，支持多平台（闲鱼、淘宝等）的消息接入、路由和投递。系统采用四层架构设计，支持异步消息处理、多重可用性保障和多语言国际化。

## 系统要求

- Go 1.22+
- Node.js 18+
- Python 3.9+（用于适配器）
- Redis（可选，用于缓存）
- PostgreSQL 或 SQLite

## 安装步骤

### 1. 克隆项目

```bash
git clone <repository-url>
cd E-SP-Line2
```

### 2. 后端安装

```bash
go mod download
```

### 3. 前端安装

```bash
cd web
npm install
```

### 4. 配置数据库

编辑 `config/config.yaml`：

```yaml
database:
  driver: sqlite  # 或 postgres
  dsn: ./data/e-sp-line2.db
  
server:
  host: 0.0.0.0
  port: 8080
```

### 5. 启动服务

```bash
# 启动后端
go run main.go

# 启动前端（新终端）
cd web
npm run dev
```

访问 http://localhost:3000 即可使用管理界面。

## 首次使用

### 1. 创建管理员账户

首次访问系统时，需要创建管理员账户。

### 2. 配置平台

在"平台管理"页面添加需要接入的电商平台：

- 淘宝（Taobao）
- 闲鱼（Xianyu）

### 3. 创建适配器实例

在"适配器管理"页面创建适配器实例：

1. 选择平台
2. 填写账号信息（Cookie 等）
3. 配置路由规则

### 4. 启动适配器

点击"启动"按钮启动适配器实例，系统会自动连接到平台并开始接收消息。

## 核心概念

### 四层架构

1. **平台层（Platform）**：定义业务平台类型（淘宝、闲鱼等）
2. **接入器包层（Adapter Package）**：具体平台的接入实现，带版本和能力声明
3. **接入器实例层（Adapter Instance）**：真实账号或店铺的运行配置
4. **运行会话层（Adapter Session）**：实例当前在线连接状态

### 消息流

```
平台 WebSocket → 接入器实例 → 事件总线 → 核心路由 → 下游应用
                                              ↓
                                        出站命令队列
                                              ↓
                                        接入器实例 → 平台发送
```

### 路由规则

路由规则决定消息如何分发到下游应用：

- **平台匹配**：按平台类型匹配
- **实例匹配**：按具体实例匹配
- **条件匹配**：按消息内容、发送者等条件匹配

## 常见问题

### Q: 适配器启动失败？

A: 检查以下几点：
1. Cookie 是否有效
2. 网络连接是否正常
3. 查看后端日志获取详细错误信息

### Q: 消息没有路由到应用？

A: 检查：
1. 是否配置了路由规则
2. 路由规则是否启用
3. 下游应用是否在线

### Q: 如何添加新平台？

A: 参考开发者文档中的"适配器开发指南"。
